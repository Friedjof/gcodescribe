# GCodeScribe v0.6.3

This release improves canvas zoom responsiveness and adds Linux-style keyboard
shortcuts throughout the desktop workflow.

## Canvas performance

- Dense drawings keep a bounded raster preview ready during zoom and pan,
  including gestures started at high magnification. Full vector detail returns
  at rest when the bitmap resolution would be insufficient.
- SVG paths and bitmap elements are retained between gestures, avoiding repeated
  path parsing and image setup. Uniformly scaled objects use ordinary,
  pixel-compensated strokes; non-uniform transforms retain precise stroke widths.
- Wheel events are coalesced per animation frame, with one pointer-coordinate
  read per frame. Pixel, line and page deltas are normalized. Page shadows are
  suspended while navigating and at high zoom.
- Drawing geometry, saved slide data and generated toolpaths remain unchanged by
  view navigation. Synthetic 100,000-point WebKit tests under Xvfb measured about
  20–21 ms per bitmap frame compared with 79–102 ms for the previous SVG strategy;
  these development measurements are not a frame-rate guarantee.

## Keyboard workflow

- Ctrl+Tab / Ctrl+Shift+Tab and Ctrl+PageDown / Ctrl+PageUp cycle enabled
  workspaces, including overflow tabs. Alt+1–8 selects a workspace directly;
  Alt+9 selects the last. GTK Backtab is forwarded before native focus traversal
  can consume it.
- Ctrl+, opens Settings; F1 and Ctrl+? open help. New/open/save, export, preview,
  plot options, search, rename, selection, sidebar and zoom commands follow the
  active editor and appear in the localized shortcut reference.
- Text fields retain normal selection and editing. The topmost modal owns its
  shortcuts; background editors, disabled actions and input composition are
  respected. Holding a creation shortcut does not create repeated documents.
- Ctrl+S in Draw waits for pending text geometry and autosave. Ctrl+P opens plot
  options; starting the printer requires the existing explicit plot action.

## Export and fonts

- Draw exports SVG artwork or a JSON snapshot containing slide data and its
  calibration. Export is available through the File menu and Ctrl+Shift+E.
- The font editor exposes rename and export beside the current font name. F2
  renames the open font; exporting saves pending glyph changes first.
- Glyph strokes can be selected together, moved or deleted as one undoable edit.

## Updating

Quit the running desktop app before installing and relaunch it afterwards.
Projects, profiles, printers, fonts and interface preferences are retained.

For an existing system installation:

```sh
flatpak install --system ./GCodeScribe-v0.6.3.flatpak
```

For an existing user installation, use `--user` instead. The installation location
is shown by `flatpak list --app --columns=application,version,installation`.
