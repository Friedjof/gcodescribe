# GCodeScribe v0.6.4

This hotfix restores drawings that could disappear in the desktop editor and
reduces the work needed when zooming dense artwork.

## Drawing visibility

- Dense drawings now encode dark ink directly into their preview image. Paper
  stays white in both themes; theme-dependent SVG image filters are removed.
- A new bitmap is decoded before replacing the previous image. Complete vectors
  remain visible until the SVG image has loaded, and image failures restore the
  vector fallback. Source geometry and generated printer paths are unchanged.

## Zoom responsiveness

- The maximum navigation texture is 2048 pixels per edge, reducing its maximum
  area by 75% from the previous 4096-pixel limit. Detailed vectors return at rest
  when that bitmap would otherwise be enlarged.
- Small zoom adjustments reuse the decoded image while cosmetic ink width stays
  within 10% of its target, avoiding unnecessary PNG encoding and decoding.
- Wheel notches less than 250 ms apart share one gesture instead of repeatedly
  switching between vector detail and the navigation preview.

## Validation

All 649 frontend tests and the TypeScript/Vite production build passed. Native
Flatpak WebKit checks received 80 real wheel events, retained identical drawing
geometry and kept the artwork visible in both themes. One preview URL remained
active after the test, with at most two live during replacement. Software
rendering and variable host load do not establish a universal frame-rate promise.

Quit the desktop app completely before updating, then relaunch it. For an
existing system installation:

```sh
flatpak install --system ./GCodeScribe-v0.6.4.flatpak
```

Use `--user` instead for an existing user installation. Keep the application's
data directory to preserve projects, printers, profiles and fonts.
