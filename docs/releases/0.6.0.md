## Redesigned editor and guided setup

- Full-width editor with customizable workspace tabs, adjustable side panels, rulers and optional paper spacing.
- Guided setup for selecting a project and profile, connecting a printer, calibrating, creating a drawing and previewing a plot. An interactive tour introduces the main workspaces.
- Compact toolbars and contextual object properties, with paginated project, profile, gallery, font and template collections.
- Precise object measurements, accessible transform handles and live move/resize readouts. Decimal and unit inputs keep incomplete edits until they are committed.
- Zoom and pan preserve complete drawing geometry and fine line rendering, including large drawings and changes to panel sizes.

## Calibration, profiles and printer control

- Multiple named plotters can use separate USB/serial ports or OctoPrint instances. The top-bar selector shows connection status and remembers the selected printer; switching clears position references and is blocked during running or paused plots. Existing connections remain available.
- Paper calibration defaults to pen up on entry, reactivation and task changes. XY jogging lifts first on the server; automatic lifting never lowers a head that is already higher. Lowering remains an explicit calibration or test action.
- Calibration now sets the pen setup and optional parking positions before pen heights, with descriptive names and raised-only setup travel.
- Guided paper capture supports two diagonal anchors with automatically completed right-angle corners, or four individual corners for tilted paper. Generated corners remain distinguishable after editing and export/import.
- Focused arrow-key controls prevent browser scrolling and queued repeat moves; a central Home button re-references without leaving the current task. A test dot marks the current position and automatically lifts again.
- A corner-point test accompanies the frame test, marking front left, back left, back right and front right with raised travel between dots.
- Profile editing combines visual calibration with grouped detailed settings. Paper movement arrows and corner capture are directly accessible.
- Rename profiles and export JSON or XML directly from the visual editor.
- Calibration commands target an explicit profile or the selected project's profile and reject stale profile versions before pressure movements.
- Plot startup rechecks the printer connection and readiness before sending a generated job.
- Settings updates are atomic, protect pending edits and invalidate outdated connection checks. Printer configuration and connection changes share one coordinated lifecycle.
- Flatpak uses native desktop notifications with a remembered permission choice. Browser notifications distinguish completed jobs from interrupted jobs and handle permission failures.

## Plot planning and routing

- Shared immutable scene plans provide a common source for G-code generation and route optimization.
- Pen-up travel optimization accounts for physical route lengths and obstacles while retaining drawing geometry and stroke metadata.
- Obstacle travel routes remain within the printer bed. Regression tests and audit tools compare optimized plans against legacy output, including stored-slide snapshots.

## Reliability and workflow fixes

- Background task notifications can be closed together while running imports continue. Printer management is embedded in Settings, which is directly accessible from the header.
- Profile editing no longer has a global Activate action; projects choose their own profile. Out-of-area drawings offer reversible clipping alongside proportional fitting.
- Slide actions use direct buttons, slide loading keeps the editor mounted, and the orientation marker sits on the green top edge at every rotation. New-project forms size to their contents, and Sudoku generates from the displayed seed automatically.
- A translucent backside reference previews another slide in the correct orientation for long-edge or short-edge flipping without changing the drawing or exported G-code.
- AI image generation and edits can use either the OpenAI API or a separate Codex/ChatGPT sign-in through the official Codex CLI app-server protocol. The Flatpak includes the tested Codex CLI; other installations require it on the server's PATH. Provider selection is explicit and never automatically changes billing mode.
- Late editor responses, pending changes, template insertions and plot results stay associated with their original page, project and profile.
- Deleted pages reject late writes; local drafts survive failed discard/reload attempts.
- Preview requests are cancelled when replaced, and completed requests cannot reopen a closed dialog.
- Dialogs coordinate keyboard focus and Escape handling. Navigation keys cannot accidentally jog the printer while a dialog is open.
- Template parameters are edited inline; generated pages retain their random codes. OSM previews reject stale responses.
- Development servers poll for changes so hot reload works when Linux's inotify watcher limit is exhausted.
- Python source distributions retain the production frontend so wheels rebuilt from them can serve the web application.

## Installation and upgrade

For the GTK desktop application, install the attached `GCodeScribe-v0.6.0.flatpak`.
For the CLI and web application on a compatible Debian/Ubuntu system with Python 3.12 available:

```sh
sudo apt install ./gcodescribe_0.6.0_amd64.deb
gcodescribe-web
```

Open <http://localhost:8000>. RPM and AppImage packages are also provided by the release workflow.

Back up your application data before upgrading. Regenerate existing jobs if their calibration fingerprint has changed. Printer movement is covered by automated tests with simulated printers; physical plotter validation remains a separate step.
