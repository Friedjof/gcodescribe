## New features

- **Projects and slides:** project overview with search, archive/restore, dedicated calibration profiles, nested folders, slide thumbnails and moving slides between projects. Existing pages are migrated with backups.
- **Xournal++ import:** import native `.xopp` pen strokes, select pages and retain stroke order. Optional pressure follows the original segment widths within a calibrated Z range.
- **Calibration and control:** configurable park and pen insertion positions, insertion pressure adjustment, adjustable Z speed limit and a movement test. Paper controls use the selected project's calibration.
- **Background imports:** uploads and re-rendering run as background tasks with progress and gallery results.
- **OSM maps:** persistent download cache, bounded retries and tiled downloads, detail controls, filters and selectable stroke routing.
- **Designer tools:** contextual toolbar, object actions, page fitting and improved image/text controls.
- **Handwriting:** five additional styles, including the bundled Caveat font, and SVG handwriting tracing.

## Performance

- Geometry preparation runs in workers; canvas interaction avoids repeatedly processing large drawings.
- Gallery thumbnails and application views load on demand.
- Live viewers receive incremental scene updates and retain a complete reconnect snapshot.

## Bug fixes

- Block manual movement and profile changes while a plot is active; restore the saved position, Z height, feedrate and coordinate mode when resuming a serial plot.
- Validate project jobs against their current project calibration before homing or sending commands.
- Keep manual plot-area margins stable when repeatedly applying changes.
- Minimize continuous-path retracing using physical edge lengths.
- Correct 3D preview sizing, bed visibility controls and numeric field updates.
- Preserve physical speeds when upgrading old calibration files and profile imports from mm/min to mm/s. Original profile files are backed up before migration.
- Repair packaged `vpype` invocation after installation so document conversion works outside the build directory.

## Installation

Download `gcodescribe_0.5.0_amd64.deb` from the release assets and install it on a compatible Debian/Ubuntu system with Python 3.12 available:

```sh
sudo apt install ./gcodescribe_0.5.0_amd64.deb
gcodescribe-web
```

Open <http://localhost:8000>. The Debian package provides the CLI and web application. The GTK desktop application is available as a Flatpak asset.

Back up your application data before upgrading. Existing jobs whose calibration fingerprint has changed must be generated again. Hardware movement has automated coverage with simulated printers; this release was not verified on a physical plotter.
