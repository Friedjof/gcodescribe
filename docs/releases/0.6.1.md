# GCodeScribe v0.6.1

This release improves desktop interaction, guides pen insertion more clearly, and reorganises documentation and model downloads.

## Desktop and interface

- Printer selection, language, Settings and the theme button are directly accessible in the header, in that order.
- The desktop app supports the Linux system theme and manual light/dark switching. Labels are not selectable; text fields and copy fields remain selectable.
- Server and security settings are hidden on the desktop. Font management, import and export are available in the Font Editor workspace.
- Background tasks can be reduced to a small bell with a counter and dismissed together.
- The setup tour works without a configured printer. Offline views avoid unnecessary position requests.

## Drawing, preview and printers

- A visible pen button opens a confirmation and illustrated insertion instructions. Travel uses the project's insertion height, including its pressure offset.
- Zoom gestures retain the prepared view of large drawings and avoid the expensive SVG mask. Exports retain the full geometry.
- The large G-code preview can hide travel paths and show paper/profile outlines. Saved jobs use their own calibration snapshot.
- All STL import options appear together on the left. Orbit, Trackball and CAD provide three control modes; free rotations also apply to the 2D drawing.
- Printer tests distinguish OctoPrint availability, API access and the physical printer connection. USB firmware probes require a separate confirmation and never open an already-owned port.

## Languages

- English, German, Bavarian, French and Spanish catalogues have matching coverage. Project management uses translatable text rather than hardcoded German labels.
- Automated checks validate translation keys, interpolation variables and entries referenced in the source code.

## Integrations

- Desktop MCP uses a persistent local port and remains token-protected. A port occupied by another application produces a clear error.
- External Codex login links open in the default browser. The login dialog was checked in GTK/WebKit; account credentials are stored separately from API credentials.

## Documentation and downloads

- A new English README with five featured screenshots, a screenshot gallery and neutral demo content.
- English UI and artwork in all eleven documentation screenshots.
- A new icon for the website and Linux packages, with matching browser icon variants.
- An editable Workshop demo font in `.gcsfont` format.
- Current v2 STLs individually and as a ZIP, plus STEP and Fusion designs. Earlier models are archived under `media/models/old/`.
- A materials list and assembly guidance for the Ai3MS pen holder.

## Updating

Existing projects, profiles, printers and fonts remain in the data directory. Existing theme preferences are retained. Check the profile and home the printer after switching printers.

Keep the application running to use desktop MCP. Copy its URL from the MCP settings; the desktop app saves the port for subsequent launches.
